68102010203 จาก html-lab ในครั้งนี้ ผมได้เรียนรู้การใช้งาน html ในการเขียนเว็บไซต์เบื้องต้น การทดลองใช้คำสั่งต่างๆให้เกิดความเข้าใจ ความเคยชินและที่สำคัญที่สุดคือการเขียนให้ถูกต้องตามไวยากรณ์ การจัดเรียงรูปแบบโปรแกรมให้เป็นระเบียบ เข้าใจง่ายต่อผู้ที่มาดูหรือใช้พัฒนาต่อ ซึ่งทำให้ผมเห็นภาพรวมของการสร้างเว็บไซต์มากขึ้น เข้าใจว่าการเขียนโค้ดที่ดีไม่ใช่แค่ให้ใช้งานได้ แต่ต้องอ่านง่ายและเป็นระบบ รวมถึงสามารถนำความรู้ที่ได้ไปต่อยอดในการเรียนหรือพัฒนาเว็บไซต์ในอนาคตต่อได้ ร่วมกับภาษาอื่นๆ ไม่ว่าจะ css ที่ใช้ตกแต่งให้ภาพรวมเว็บไซต์ดีขึ้น หรือ javascript ช่วยเพิ่มการตอบสนองกับผู้ใช้ได้ ทั้งนี้โครงสร้างของ html ก็ควรจะแข็งแรง ถูกต้องมาก่อนด้วย จะได้ง่ายกับใช้ร่วมกับภาษาอื่นๆ
